Rust Integration


NO_STD ENVIRONMENT

#![no_std] disables standard library:
  - No heap allocator
  - No panic runtime
  - No file I/O, networking
  
Required language items:
  #[panic_handler]
  #[lang = "eh_personality"]


CONFIGURATION

Cargo.toml:
  crate-type = ["staticlib"]
  panic = "abort"
  
Target: i686-toyos.json (custom)


MEMORY MANAGER

Static state:
  ALLOCATED_PAGE_COUNT: AtomicU32    Number of pages currently allocated
  NEXT_FREE_PAGE: AtomicU32          Next fresh page address (monotonic bump)
  PAGE_FREE_LIST: PageFreeList       Fixed-size stack of recycled addresses
  PAGE_STATS: PageAllocStats         Tracks free page count

Constants:
  TOTAL_PAGES   = 1024
  PAGE_SIZE     = 4096
  PAGE_POOL_START = 0x800000
  PAGE_POOL_END = PAGE_POOL_START + (TOTAL_PAGES * PAGE_SIZE)

PAGE_POOL_START starts above the kernel image. The kernel loads at 1MB and
static BSS (including 4MB of page tables) extends to roughly 5MB. Using
0x800000 (8MB) avoids overwriting kernel text/data, which previously caused
an Invalid Opcode panic when paging was enabled.


EXPORTED FUNCTIONS

All use extern "C" for C ABI:

rust_memory_init()
  Reset allocator: zero ALLOCATED_PAGE_COUNT, reset NEXT_FREE_PAGE to
  PAGE_POOL_START, clear the free-list.

rust_allocate_page() -> u32
  Allocate a 4KB-aligned physical page.
  Checks free-list first; falls back to bumping NEXT_FREE_PAGE.
  Returns 0 if all pages are exhausted.

rust_free_page(page: u32)
  Push the page back onto the free-list for reuse.
  Validates alignment and address range before accepting.

rust_print_stats()
  Print allocated/free page counts to the terminal.

rust_get_total_memory() -> u32
rust_get_free_memory() -> u32


FFI IMPORTS

Calls C functions:

extern "C" {
    fn terminal_putchar(c: u8);
}


ATOMIC OPERATIONS

AtomicU32 provides lock-free synchronization:

fetch_add(n, Ordering::Relaxed)
  Atomically increment and return old value

Relaxed ordering is used throughout. SeqCst emits MFENCE (an SSE2
instruction) which is illegal on this bare-metal i686 target. On a
single-core kernel there is no need for a memory fence, so Relaxed is both
correct and sufficient.


ALLOCATION ALGORITHM

  Allocate:
    1. Pop from PAGE_FREE_LIST if non-empty -- return that address.
    2. CAS NEXT_FREE_PAGE from current to current+PAGE_SIZE.
    3. Return 0 if NEXT_FREE_PAGE >= PAGE_POOL_END.

  Free:
    1. Validate page is aligned and within valid range.
    2. Push address onto PAGE_FREE_LIST.
    3. Decrement ALLOCATED_PAGE_COUNT, increment free_pages.

PAGE_FREE_LIST is a plain array (TOTAL_PAGES slots) used as a stack. Safe on
uniprocessor; SMP would require atomic push/pop.


SAFETY

Unsafe required for:
  - Global mutable static
  - Calling FFI functions
  - Raw pointers

Minimal unsafe surface area.


INTEGER PRINTING

print_u32() converts a u32 to decimal digits without using division or
modulo operators. Division and modulo on u32 call __udivsi3/__umodsi3 from
compiler-rt; those symbols are not available in bare-metal builds and cause
an Invalid Opcode (UD2) trap at runtime.

Implementation uses a table of powers of ten with repeated subtraction:
  1. Find the highest power of 10 that fits into the value.
  2. Count subtractions to produce each decimal digit.
  3. Write each digit via terminal_putchar().

This avoids any dependency on the compiler runtime for integer arithmetic.
